# 双算法流水线 `444.mp4` 实验报告

实验分支：`experiment/dual-detector-pipeline`

## 目的

验证“FFmpeg场景阈值快速产生临时页面区间，时序算法最终确认页面，
匹配页面复用提前ASR，冲突页面重新识别”是否能真实缩短完整处理时间。

稳定版本v1.3.0仍保留在`main`和`v1.3.0`标签，本实验没有修改稳定分支。

## 实验流程

1. 用与时序算法相同的投影区域启动流式FFmpeg场景检测；
2. 场景候选间隔不足5秒时视为片头动画或短暂变化，不立即切页；
3. 每出现一个有效场景边界，立即将刚结束的临时区间提交小米MiMo ASR；
4. 时序算法同时完成全局采样、动画合并、边界精修和高清截图；
5. 场景边界与时序边界误差不超过2秒，且页面内部没有额外候选时，
   直接复用提前ASR；
6. 边界缺失或页面内部存在额外候选时，按时序算法最终区间重新ASR；
7. 最终页面文字准备好后，使用原有多模态LLM逐页评分。

## 真实结果

| 总耗时 | 366.612秒 | 299.858秒 | 减少66.754秒，约18.2% |
| 首个ASR提交 | 124.614秒 | 3.587秒 | 提前121.027秒 |
| 首个ASR完成 | 130.270秒 | 16.435秒 | 提前113.835秒 |
| 时序页面检测完成 | 156.578秒 | 239.575秒 | 变慢82.997秒 |
| 页面数 | 24 | 24 | 一致 |
| 场景原始候选 | - | 24 | - |
| 过滤短片头候选后 | - | 23 | - |
| 时序边界匹配 | - | 22/23 | 95.65% |
| 直接复用提前ASR | - | 21/24页 | 87.5% |
| 按最终区间重识别 | - | 第15、16、22页 | 3页 |
| 转写字符数 | 19241 | 19189 | 少52字，约0.27% |
| LLM平均分 | 97.62 | 96.96 | 低0.66分 |

22个匹配边界的最大误差为0.117秒。场景法漏掉约1886秒的换页，因此
第15、16页重新识别；约2773秒出现额外候选，因此第22页重新识别。

转写文本与v1.3.0逐页对比：

- 24页平均字符序列相似度99.09%；
- 最低为第14页92.5%，其场景与时序边界两端误差均只有0.067秒，
  差异主要来自云端ASR重复请求的生成波动，不能仅据此认定切分错误；
- 24页均有文字，24页LLM评分全部成功；
- 临时WAV残留为0。

## 代价

提前ASR覆盖完整视频一次，冲突页面又需要局部重识别：

| 云端资源 | v1.3.0 | 双算法实验 | 增加 |
|---|---:|---:|---:|
| ASR音频分块请求 | 52 | 60 | 约15.4% |
| 上传临时音频 | 106,767,640字节 | 124,912,274字节 | 约17.0% |

另外，两套检测同时各自解码视频，产生明显CPU和磁盘竞争，使时序检测从
156.578秒变为239.575秒。尽管如此，总时间仍缩短66.754秒，证明提前
ASR复用的收益大于重复解码造成的损失。

## 结论

双算法方向有效，值得继续优化，但本实验版本暂不合并到`main`。

下一步最有价值的优化不是提高云端并发，而是让场景检测和时序采样共享
一次FFmpeg解码，消除82.997秒的本地资源竞争。完成后再用相同视频复测，
若页面数、重识别页数和文字相似度保持稳定，再考虑加入GUI实验开关。
